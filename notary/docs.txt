# Project: Professional US Notary Business Website

Build a modern, professional, mobile-first website for a US-based Notary Public / Mobile Notary / Notary Signing Agent.

The main purpose of the website is to help the notary:

- Build trust and credibility
- Clearly present their services
- Rank better for local notary-related searches
- Allow customers to easily call, text, contact, or request an appointment
- Showcase service areas, experience, reviews, and qualifications
- Convert website visitors into real leads

The website should look premium and trustworthy, but remain simple and easy to navigate.

---

# 1. Project Goal

Create a professional business website for a notary who currently does not have a website.

The website should act as their main online presence.

Primary conversions:

- Call the notary
- Send a text message
- Request an appointment
- Submit a contact form
- Request a quote

The website should not feel like a generic template.

It should feel like a real local professional service business.

---

# 2. Target Audience

The website should be designed for people who need notary services, including:

- Individuals
- Homeowners
- Buyers and sellers
- Borrowers
- Attorneys
- Title companies
- Escrow companies
- Real estate professionals
- Businesses
- Hospitals
- Nursing homes
- Senior care facilities
- Families
- Loan signing companies

Many users will visit from mobile devices, so mobile UX is extremely important.

---

# 3. Design Style

Use a clean, professional, trustworthy design.

Suggested style:

- White/light background
- Dark navy or deep blue primary color
- Optional gold or warm accent
- Modern typography
- Large clear headings
- Soft shadows
- Rounded cards
- Good spacing
- Professional imagery
- Minimal unnecessary animation

Avoid:

- Neon colors
- Overly playful UI
- Heavy gradients
- Complicated dashboards
- Too many animations
- Cluttered layouts

The website should feel appropriate for a legal/document-related professional service.
